## Detailed Findings

### [CRITICAL] agent-loop:440-465 — Stale reasoningEffort from prior model leaked across route switch
- **Category**: Correctness / Session Request Reconstruction
- **Description**: When a session switched models between turns (or via `agent/request` waterfall), `seedConfig` and `requestProposal(persistedHeader!)` retained `persistedHeader.config.reasoningEffort = 'off'`. When targeting a reasoning-only model like `stealth/ox-alpha` under `vision-toolkit-oxa` (which supports only e.g. `high`, `max` but not `off`), `LlmRuntime.resolveCallWithInfo` threw `UNSUPPORTED_REASONING_EFFORT: provider "vision-toolkit-oxa" model "stealth/ox-alpha" does not support reasoning effort "off"`.
- **Remediation**: In `packages/core/agent-loop/src/agent.ts`, enforce route matching before folding `persistedHeader.config.reasoningEffort`. When `proposedRouteChanged` occurs in `agent/request`, strip inherited `reasoningEffort` so the new model's own adapter defaults and capabilities apply cleanly.
