## 架构决策：对齐 openai/codex 的发布形态

codex 的发布形态 = **每个目标平台一个自包含原生 exe + 便携 ZIP，零依赖、无安装器**。
本仓库技术栈为 TypeScript/Node，其官方等价物是**仓库自有的 `@yao-pkg/pkg --sea` 单文件管线**（`scripts/build-exe-for-python-sdk.ts`）：
- 产物 `deepseek-harness-sdk-runtime-win-x64.exe`：内嵌 Node 24 运行时 + 全部 dsh 闭包 + Web 前端 dist（ASSET_GLOBS 显式包含 `dsh-web-frontend/dist/**/*`）；
- 有仓库测试门禁（`build-exe-for-python-sdk.spec.ts`）与已归档架构说明。

**弃用方案**（旧 `package-windows-desktop.ts` 的"node.exe + 手工拷贝目录树"）已证实不可靠：
- GET `/` 返回 404（frontend-static fallback 未生效，手工拷贝树与 pnpm 布局存在不可复现的差异）；
- 打包巨慢（复制 4895+ 文件）、ZIP 1.34GB；
- 与用户本机并行打包互相竞态（多次"目录凭空消失"根因）。

**新发布目录仅 7 个文件**：`DeepSeek-Harness.exe`（窗口宿主 13KB）、`dsh-runtime.exe`（单文件运行时）、`dsh-runtime-rg.exe`（搜索边车，命名遵循 `tool-fs-search` 的 `<exe>-rg.exe` 约定）、3 个 WebView2 DLL、说明 txt。

## Findings

### Finding 1 [Critical] 手工拷贝树的 Web 页面 404
- **File**: 旧 `scripts/package-windows-desktop.ts`（整树物化逻辑，已整体移除）
- **Evidence**: 同机对照实验——仓库树启动 `dsh web` 后 `curl` 带 Cookie GET `/` → **200 + HTML**；打包树同流程 → **404**（`webserver` 无路由且 fallback 座缺失，无 warn 日志）。两轮独立复现一致。
- **Fix**: 不再手工拷贝运行树；改用 pkg 管线整树内嵌（进行中，见 Finding 4 验证）。

### Finding 2 [Critical] 端口契约：必须固定官方端口 3080
- **File**: `scripts/desktop-host/Program.cs`
- **Fix**: `OfficialPort = 3080` 常量；启动前 TcpListener 探测，被占用即弹明确中文错误并退出——**绝不静默换随机端口**（换端口即违反产品契约）。`GetFreePort()` 已删除。

### Finding 3 [Warning] ZIP 步骤平台兼容性
- **File**: `scripts/package-windows-desktop.ts` [4/4]
- **Fix**: `tar.exe -a -c -f <相对名> -C dist-desktop .` + `cwd: root`——相对路径从语法层消除盘符冒号被 bsdtar 当远程主机的问题；不依赖 `--force-local`（Windows bsdtar 不支持）。已实测通过（exit 0，ZIP 生成）。

### Finding 4 [Warning] 单文件运行时与宿主的集成正确性（待验证）
- `dsh-runtime.exe` 必须以 `web --port 3080 --no-open` 启动并通过 stdout 播报 token URL（宿主依赖）；
- ripgrep 边车必须改名 `dsh-runtime-rg.exe` 并同目录放置（`search-core.ts:175` 约定）；
- Stage 3 将以 curl 全链路（token 303 → Cookie → GET / 200 HTML）在 3080 端口实测。

### Finding 5 [Privacy - Verified Safe] 隐私与凭证隔离（复核维持）
1. 打包第 2 步 `rmSync(outDir)` 先清空 dist-desktop，历史 `user_data/`（含 API Key、Cookie）不可能进入发布 ZIP；
2. `DSH_HOME` 与 WebView2 数据分目录：`user_data/`（产品数据）+ `user_data/webview2/`（浏览器轮廓），本次已分离；
3. `.env` 永不进入产物（仅显式拷贝 7 个白名单文件）；
4. 说明 txt 明示"user_data 含 API Key，勿外发"。

### Finding 6 [Security - Verified Safe] 外链协议白名单（维持上轮加固）
仅 `http://`/`https://` 可经 `UseShellExecute` 交给系统浏览器，其余 scheme 静默拦截。
