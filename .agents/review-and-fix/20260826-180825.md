## Root cause (verified against deployment data)

`~/.dsh/settings.yaml` `agent-default-model: {provider: vision-toolkit-oxa, model: stealth/ox-alpha, reasoningEffort: off}` seeds every header-less session's selection (web gateway getter fallback and headless bundle alike), while `stealth/ox-alpha` is a hand-declared llm-pi-ai model without `reasoningEfforts`, so the adapter reports no reasoning capability and `LlmRuntime.resolveCallWithInfo` rejects any requested effort. The 17:45 route-switch guard could not fire: provider and model were unchanged.
